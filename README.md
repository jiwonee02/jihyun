# 인왕동사지 복원 설계 — 디지털 전시

React + Vite 기반의 경주 인왕동사지 복원 설계 포트폴리오입니다.

제공된 「사진 원본.zip」의 사진 26장과 「텍스트 정리.txt」의 본문을 반영했습니다. 대상지 소개와 역사, 유구, 배치 해석, 용척 산정, 금당·십자형 건물·회랑 고증, 유구와 복원 비교, 공간 투시도, 마무리로 구성합니다.

이미지는 `public/images/originals`에 보관하고 `src/assets.js`에서 연결합니다. 대상지 사진 `2.jpg`는 웹 열람을 위해 긴 가로 폭 2600px 이내로 조정했습니다. 본문은 `src/main.jsx`에 있습니다.

`npm run dev`로 실행하고 `npm run build`로 배포 파일을 생성합니다. 기존 GitHub Actions를 통한 GitHub Pages 배포를 지원합니다.

스크롤 등장 효과, 비교 슬라이더, 사진·도면 확대, 키보드 닫기와 작은 화면의 세로 배치를 지원하며 동작 줄이기 설정을 존중합니다.
