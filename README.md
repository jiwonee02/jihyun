# 인왕동 사지 복원 설계 — 8개 장면의 디지털 전시

React + Vite 프론트엔드입니다. 흰색과 메인 색상 #6FABB8을 사용합니다.

1. 도입
2. 대상지 소개
3. 유적의 흔적
4. 배치 해석
5. 복원 과정
6. 이미지 비교
7. 공간 경험
8. 마무리

`npm run dev`로 실행하고 `npm run build`로 배포 파일을 생성합니다. 포함된 GitHub Actions로 GitHub Pages 배포가 가능합니다.

사진은 디자인 검토를 위한 황룡사 예시이며 실제 인왕동 사지 복원안이 아닙니다. `src/assets.js`에서 교체합니다. 설계 설명 또한 예시 제안이며 `src/main.jsx`에서 수정합니다.

예시 이미지 출처: https://aha.nrich.go.kr/HNSContents/StoryMode/index.html
유적 소개 참고: 경주시 인왕동사지 복원·정비 안내.

화면 진입에 따른 순차 등장, 이미지 이동, 사진 공개 효과, 비교 슬라이더, 도면 확대를 지원합니다. 작은 화면은 세로 배치로 전환됩니다. 동작 줄이기 설정을 존중합니다.
